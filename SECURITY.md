# Security Policy

This repository hosts the source for [nerymed.hu](https://nerymed.hu), a live production website. Issues and Projects are disabled here — please report security concerns privately instead of through a public channel.

## Reporting a Vulnerability

Use the contact form on [nerymed.hu](https://nerymed.hu) to reach us privately, with details of the issue (what you found, how to reproduce it, and its potential impact). Please don't disclose it publicly until we've had a chance to address it.

We'll acknowledge your report within a few business days and let you know once a fix is deployed.

## Scope

This covers the site's source code and the contact-form backend (`server/`). It does not cover the hosting infrastructure itself, which is documented separately and not in this repository.
