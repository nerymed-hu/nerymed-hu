# NeryMed

Source for [nerymed.hu](https://nerymed.hu) — the website for Dr. Nery Klaudia Krisztina's medical practice (Érd, Hungary).

Built with [Astro](https://astro.build) + [Tailwind CSS](https://tailwindcss.com), with a small Node.js/Express contact-form backend (`server/`).

Issues and Projects are disabled on this repo. To get in touch, use the contact form on [nerymed.hu](https://nerymed.hu) or email nerymedkft@gmail.com — for security concerns specifically, see [SECURITY.md](SECURITY.md).
